# ⚽ Penalty Shootout Game

Welcome to my Penalty Shootout game built in Java! 

## 🚀 How to Download and Play
1. Go to the **Releases** tab on the right side of this page.
2. Download the latest **`PenaltyShootoutProject.jar`** file.
3. Make sure you have **Java** installed on your computer.
4. Double-click the file to launch the game! (If double-clicking doesn't open it, download the `Play.bat` file from this repository into the same folder and double-click that instead).

## 🎮 Game Controls
* **[Spacebar]** - Kick the soccer ball!
* **[Left / Right Arrows]** - Aim your shot.
