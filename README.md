# ⚽ Penalty Shootout Game

Welcome to my Penalty Shootout game built in Java! 

## 🎮 How to Play

### Step 1: Download the Application
1. Look at the right side of this GitHub page and click on **Releases**.
2. Download the latest **`PenaltyShootoutProject.jar`** file to your computer.

### Step 2: Run the Game
1. Make sure you have **Java** installed on your computer.
2. Double-click the **`PenaltyShootoutProject.jar`** file to launch and start playing!
3. *Note: If double-clicking doesn't open the game window due to your Windows folder settings, simply download the `Play.bat` file from this repository into the exact same folder and double-click that instead.*

---

## 🕹️ Game Controls
* **[Spacebar]** — Kick the soccer ball!
* **[Left / Right Arrow Keys]** — Aim your shot at the goal net.
